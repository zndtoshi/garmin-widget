# Backend (FastAPI)

Private FastAPI service for the garmin-widget Android client.

**Status:** structure only. No application code yet (Milestone 1). Implementation begins at Milestone 2.

## Planned layout

```
backend/
├── app/              # Application package (future)
├── tests/            # Local tests (future)
├── Dockerfile        # Container build (Milestone 2)
├── README.md
├── pyproject.toml    # Project metadata + dependencies (uv)
└── uv.lock           # Lockfile generated by uv when dependencies are added
```

## Dependency management

Use **[uv](https://github.com/astral-sh/uv)** with:

- `pyproject.toml`
- `uv.lock`

Do **not** introduce `requirements.txt`.

When dependencies are added (Milestone 2+), generate and commit `uv.lock`.

## Responsibilities (see PROJECT.md)

Separated concerns:

- Configuration
- API authentication (widget bearer token)
- REST API (normalized payloads only)
- Garmin authentication / session management
- Garmin client (returns normalized internal models)
- Metric normalization
- Cache / persistence
- Error handling

The REST API must not depend on raw Garmin response structures.

## Endpoints (planned)

| Method | Path | Notes |
|--------|------|--------|
| `GET` | `/health` | No Garmin contact |
| `GET` | `/api/v1/widget/latest` | Cache only |
| `POST` | `/api/v1/widget/refresh` | Cooldown, lock, Garmin, fallback |
| `GET` | `/api/v1/widget/history` | Future only — out of scope for v1 |

## Security

Never commit Garmin credentials, session tokens, widget bearer tokens, `.env` files, or local persistent data. See the repository `.gitignore`.
